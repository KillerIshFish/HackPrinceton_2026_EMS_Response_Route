Find the 911 caller inside the building.

A phone fix gives an address and a rough height. The caller says things like "I'm locked in a bathroom". We combine both with the building's floor plan to give every room a probability, and hand responders the search order with the shortest expected time to reach the caller.

How it works

Three kinds of evidence, each turned into a likelihood per room and multiplied together. Each new sentence from the caller updates the result.

core/phone_likelihood.py

Phone location

Horizontal fix plus barometric height (the z-axis). Height is compared with each floor, so a 12.6 m reading narrows the call to floors 3 and 4.

parser/ · core/clue_likelihood.py

What the caller says

Room types, window views and routes ("came up the stairs and turned right"). Parsed by keyword rules offline or by Claude Haiku, then checked against a fixed vocabulary.

ingest/ · core/prior.py

The building itself

Rooms, doors, stairs and windows from Matterport scans, CoStar records and aerial imagery, or a generated model built from an address.

Console tour

The console is for the dispatcher. What you can do on your first call:

  1. Pick a buildingUse the building menu in the header. The synthetic 100 Princeton Tech Center needs no data or keys; real buildings appear once they're built.
  2. Step through the callPress Next Call Turn to add evidence one turn at a time and watch the heatmap and search plan change.
  3. Type what the caller saidUse the Caller said box for anything free-form. Switch the parser between Rules and Claude Haiku.
  4. Mark a room searchedMark Cleared on a stop means the crew searched it and didn't find the caller. That room's probability drops and the plan is rebuilt from where the crew is standing.
  5. Look inside and aroundOn real buildings, 3D opens the Matterport scan of a room and Approach shows aerial imagery with entrances and staging spots.

Run it yourself

You need Python 3.11+, uv and Node 20+. Start the backend and the frontend in two terminals, then open http://localhost:5173.

1 · Backend (repo root)

uv sync
uv run uvicorn api.server:app --reload --port 8000

2 · Frontend

cd web
npm install
npm run dev

Optional: put ANTHROPIC_API_KEY in .env to turn on the Claude Haiku parser. Without it the console uses keyword rules.
